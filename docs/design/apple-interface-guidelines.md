# DSH Atlas Apple Interface Guidelines

> 本文是 Atlas 前端视觉与交互的当前基准。它更新了早期偏暖、偏文档式的视觉方向；不改变 DSH 原生会话、模型、权限或任何服务端行为。

## 1. 产品感受

Atlas 应像一个安静、可靠的 DSH 会话工作台：用户在画布中阅读、整理和继续工作时，优先感受到方向感、控制感和清晰的执行边界，而不是装饰性 UI。

- **结构优先**：侧栏、顶部操作区、画布、卡片和弹层的位置是稳定的空间锚点，不因视觉升级而移动。
- **材质表达层级**：顶部栏和侧栏是结构性半透明材质；对话卡片可以使用较轻的玻璃承载面；菜单、选择器和确认操作必须使用不透明实体面。不要让可点击的选项与其背后的文本发生视觉混叠。
- **色彩克制**：基础界面使用冷中性灰与 DSH 蓝；语义只使用蓝（重点）、绿（结论）、琥珀（待验证）、红（危险）和青（转向）。禁止以紫色作为默认“AI”强调色。
- **用户掌控**：模型、权限、上下文和删除操作必须有清晰当前值、可见焦点与即时反馈；危险权限与删除继续保留明确确认。

## 2. 颜色与材质

| Token | 浅色 | 用途 |
| --- | --- | --- |
| `--bg` | `#ffffff` | 实体卡片、输入与内容承载面 |
| `--surface` | `#f4f5f7` | 画布背景和次级区域 |
| `--surface-raised` | `#ffffff` | 高优先级内容表面 |
| `--accent` | `#0a6ed1` | 当前选中、主要动作、重点 |
| `--success` | `#21864b` | 关键结论与成功 |
| `--warn` | `#a85b00` | 待验证与分支提示 |
| `--danger` | `#c63b32` | 删除和错误 |

半透明区域使用 `--material` 或 `--material-heavy`，配合 20–28px blur。高对比度或减少透明效果时改为实体 `--bg`，不能依赖模糊维持可读性。

## 3. 字体与信息层级

- 优先使用系统字体：`-apple-system`、`BlinkMacSystemFont`、`SF Pro`、`PingFang SC`、`Microsoft YaHei UI`、`Segoe UI`。
- 标题使用更紧的字距（约 `-.02em` 至 `-.03em`）和 680–720 字重；正文保持自然字距与 1.65–1.7 行高。
- 微标签和性能数据使用等宽字体与 tabular nums；它们应当辅助扫描，而非压过主要内容。
- 卡片标题是第一阅读层，摘要是第二层，按钮/指标是第三层。不要仅靠颜色建立层级。

## 4. 组件规则

### 卡片

- 固定画布中的位置、尺寸、连接关系与现有内容顺序。
- 使用 16px 圆角、轻玻璃材质、轻边框和低对比阴影；悬停只上浮 2px，不能遮挡或改变邻近卡片布局。
- 状态颜色只用于边框、底色和芯片，正文始终保持中性色可读性。
- 单卡性能条是不可选的被动信息层，使用低对比表面和等宽数字。

### 输入框与菜单

- 输入框是卡片内最具执行性的表面，使用 18px 圆角和较实的背景。
- 焦点以 3px 柔和蓝色光环表达，不使用叠加的硬蓝边。
- 菜单从触发控件方向 materialize，并保持触发器附近的空间关系；菜单背景必须是实体 `--surface-raised`，不能使用 `backdrop-filter` 或透明底色；点击空白处关闭的行为保持不变。
- 卡片编辑器的模型、权限、命令和上下文菜单统一显示在整张卡片的上方，不能仅锚定在输入框上方；卡片缩放后仍需保留约 8–10px 的逻辑间距。
- 工具栏按钮保持紧凑、可点击、单行；窄卡片仍由现有响应式规则分为两行。

### 弹窗与反馈

- 对话框采用更厚的材质、20px 圆角和适度背景模糊，强调当前任务但不丢失画布上下文。
- 按钮在按下瞬间缩放到 `0.975`，仅作为直接反馈；拖拽中的画布与卡片不得被 CSS 动画干扰。
- 动画以 150–180ms 的平滑缓出为主。用户启用减少动态效果时只保留极短淡入淡出。

## 5. 禁止事项

- 不增加新的业务流程、数据模型或后端 API 来完成视觉设计。
- 不用大面积渐变、持续循环动画、夸张投影或装饰性发光抢占会话内容。
- 不将每个区域都玻璃化；需要选择、确认或删除的菜单必须是实体表面。
- 不改变卡片、侧栏、顶部栏、画布控件与原生对话能力的相对位置，除非另有产品需求确认。

## 6. 验收清单

- 浅色和深色下，正文、元信息、状态标签和禁用态都可读。
- 顶部栏、侧栏、菜单和对话框层级清楚，卡片仍是画布阅读焦点。
- 键盘焦点明显；按压有即时反馈；`prefers-reduced-motion` 与 `prefers-reduced-transparency` 都有降级样式。
- 桌面与窄卡片下的布局、模型/权限/上下文功能保持原有行为。
- 桌面侧栏可沿右侧分隔线在 188–320px 内连续向左或向右拖动；宽度需要保存在本地，且至少为画布保留 640px 的工作空间。
- 收缩侧栏保留“新会话、搜索、筛选、工作目录、会话”五类入口；弹层使用实体背景，沿图标右侧展开，点击选项或空白处关闭。
